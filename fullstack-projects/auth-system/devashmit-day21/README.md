# 🚀 JWT Auth System (React + FastAPI) — Day 21 Fullstack Challenge

**Issue:** [#396](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/396) | Week 3 | Advanced

## 📋 Description

Complete auth system: Register, Login, protected Dashboard, Logout. FastAPI + JWT + bcrypt. React frontend with protected routes. Token in httpOnly cookie.

## 🚀 How to Run
```bash
cd backend && pip install fastapi uvicorn python-jose passlib[bcrypt] python-multipart
uvicorn main:app --reload
cd frontend && npm install && npm run dev
```
