# 🔐 Network Packet Sniffer with Scapy — Day 21 Cybersecurity Challenge

**Issue:** [#394](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/394) | Week 3 | Beginner

## 📋 Description

Packet sniffer using Scapy. Captures live packets, displays source/dest IP, protocol, payload size. Saves to `.pcap` viewable in Wireshark.

> ⚠️ Only use on networks you own or have permission to monitor.

## 🚀 How to Run
```bash
pip install scapy
# Run as root/admin
python sniffer.py
```
