# ⚛️ Command Palette (Ctrl+K Search) — Day 21 React Challenge

**Issue:** [#390](https://github.com/abhishek-goswami1/Daily-Dev-Challenges/issues/390) | Week 3 | Advanced

## 📋 Description

VS Code-style command palette triggered by Ctrl+K. Fuzzy search through 20+ commands, keyboard navigation (↑↓ Enter Esc), executes commands on selection.

## ✨ Features
- Ctrl+K / Cmd+K to open/close
- Fuzzy search through 21 commands
- Keyboard navigation (↑↓ = move, Enter = execute, Esc = close)
- Command categories with icons
- Toast notification on execute
- Smooth animation

## 🚀 How to Run
```bash
npm install && npm run dev
```
Press Ctrl+K to open the palette.
